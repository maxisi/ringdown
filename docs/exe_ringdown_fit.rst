ringdown_fit
============

Sets up and runs a single ringdown fit from a configuration file (see
:doc:`config_file`).

.. argparse::
   :filename: ../ringdown/cli/ringdown_fit.py
   :func: get_parser
   :prog: ringdown_fit

The configuration file format is described in :doc:`config_file`; an
example, ``ringdown_fit_example.ini``, can be found in the ``etc/``
directory of the source repository.
